# Tech Shop - eCommerce Website

This is a simple eCommerce website for a tech shop, built with PHP.

## Features

* **Product Listing:** View a list of available tech products.
* **Shopping Cart:** Add products to a shopping cart and update quantities.
* **Checkout:** A simple checkout process to simulate an order.
* **Responsive Design:** The website is designed to work on different screen sizes.

## Getting Started

These instructions will get you a copy of the project up and running on your local machine for development and testing purposes.

### Prerequisites

* A web server with PHP support (e.g., Apache, Nginx)
* PHP 5.6 or higher

### Installation

1. **Clone the repository:**
   ```bash
   git clone https://github.com/your-username/tech-shop.git
   ```
2. **Navigate to the project directory:**
   ```bash
   cd tech-shop
   ```
3. **Start the PHP built-in web server:**
   ```bash
   php -S localhost:8000
   ```
4. **Open your browser and navigate to `http://localhost:8000`**

## Usage

* **Browse Products:** Go to the homepage or the "Products" page to see the list of available items.
* **Add to Cart:** Click the "Add to Cart" button to add a product to your shopping cart.
* **View Cart:** Click on the cart icon in the navigation bar to view the items in your cart. You can update the quantity of each item or remove them from the cart.
* **Checkout:** When you're ready to purchase, proceed to the checkout page from the cart. Fill in your details and confirm the order.
